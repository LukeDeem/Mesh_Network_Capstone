# Mesh_Network_Capstone
The goal of this project is to develop a wearable device that has a single button as a physical
input. When the button is pressed, the device should record the unique ID of the unit, the
duration of the button press, and a timestamp of when the event occurred. Each ID, duration, and
timestamp set is called an Event


We want to achieve a minimum of 20ft but want to extend this reach as far as we can manage.

Requirements:
1) The unit must have a battery life of one week.
2) The unit must weigh less than five pounds and be no thicker than one inch.
3) The unit must be self-contained in one package, so no external antenna
